# HR-Analytics-SQL-Project
HR Analytics Project using Snowflake SQL for Data Analysis

## Project Overview
This project focuses on analysing Human Resources data using Snowflake SQL to generate meaningful business insights and support data-driven HR decisions.

## Business Objectives
- Analyse employee distribution across departments.
- Identify salary trends.
- Understand employee demographics.
- Analyse department-wise salary expenses.
- Generate insights to support HR decision-making.

## Tools & Technologies
- Snowflake
- SQL

## SQL Concepts Used
- Data Definition Language (DDL)
- Data Manipulation Language (DML)
- Joins
- Common Table Expressions (CTEs)
- Window Functions
- CASE Statements
- Aggregate Functions

## Project Structure
- SQL_Queries – SQL scripts for analysis.
- Dataset – HR sample dataset.
- Screenshots – Snowflake query execution and results.

## Key Skills Demonstrated
SQL, Data Analysis, Data Cleaning, Analytical Thinking, Business Insights.
